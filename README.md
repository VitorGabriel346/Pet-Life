# 🐾 Pet Life - Sistema Integrado de Apoio ao Bem-Estar Animal

> **Projeto Interdisciplinar (CONTEEX - FAM)**  
> Aplicação desenvolvida para otimizar a gestão de cuidados com pets, conectar tutores, médicos veterinários, passeadores e lojas parceiras.

## 🚀 Evolução Interdisciplinar por Semestre

### 🔹 1º Semestre
- *Início do projeto e levantamento preliminar (concepção inicial do grupo).*

### 🔹 2º Semestre: Modelagem e Banco de Dados (9º CONTEEX)
- **Foco:** Engenharia de Requisitos, Modelagem Conceitual e Lógica de Banco de Dados[cite: 1].
- **Entregáveis:** 
  - Criação do Diagrama Entidade-Relacionamento (DER) integrando entidades como `Usuário`, `Pet`, `Raça`, `Passeador` e `Agendamento`.
  - Apresentação no **9º Congresso de Projetos Interdisciplinares (CONTEEX - FAM)**.
  - Validação de requisitos com cliente real (tutora de cães).

### 🔹 3º Semestre: Análise de Requisitos e Visão Veterinária (10º CONTEEX)
- **Foco:** Engenharia de Software e Modelagem UML focada na visão do profissional veterinário.
- **Entregáveis:**
  - Desenvolvimento do **Diagrama de Casos de Uso** (UML) detalhando os papéis de *Tutor*, *Prestador de Serviço*, *Veterinário* e *Loja Parceira*.
  - Especificação dos Requisitos Funcionais (Login, Agendamento, Emissão de Receita, Prontuário/Vacinação).
  - Elaboração e submissão do Artigo Científico: *"Pet Life: Análise dos Requisitos para Aplicativo de Apoio ao Bem Estar do Pet – Visão do Veterinário"*.

### 🔹 4º Semestre (Em Andamento / Próxima Etapa)
- Planejamento e implementação das novas rotas de código, integrações e refatoração da arquitetura.
